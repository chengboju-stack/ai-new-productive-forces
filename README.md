# NEXUS｜AI 新质生产力观测站

纯静态 HTML、CSS 和 JavaScript 网站，适合 GitHub Pages。网站采用章节路由视图：顶部点击章节后只显示对应章节页面；浏览器历史、章节地图、章末上一章/下一章和 NEXUS 总览入口同步切换内容，不把所有章节接成长页滚到底。

## 本地预览

在此目录运行：

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8766/`。

## 页面结构

- 四幕叙事过渡（机制、证据、实体系统、情景实验）、章节地图和章末“下一章”引导。
- 章节路由：一次只显示一个章节；顶部章节链接、章节地图和每章上一章/下一章导航直接切换页面。NEXUS 标识返回总览。
- 支持直接打开章节深链接，章节地图可快速跳转；所有动效遵守减少动态效果设置。
- 人工智能生产力作用网络：点击节点查看作用机制。
- 劳动者、劳动资料、劳动对象三要素与“五道转化条件”：开关检验技术能否进入有效工作流程；明确为解释性框架，不把开关数当作统计分数。
- 个人任务、组织流程、实体产业、社会系统四档尺度切换。
- 客服、软件开发、营销三个任务研究的交互案例：切换任务和四个工作环节，查看归一化结果、研究口径与边界。不同研究不做横向排名。
- 科研前沿仪表：在研究扩散、天气预测速度和端到端科研准确率之间切换，展示创新潜力与可靠性约束。
- 劳动影响双视角：区分年轻群体观察到的就业变化，与企业对未来用工的调查预期。
- 2026 AI Index 组织采用数据、IFR 2026 机器人部署数据、IEA 数据中心用电展望。
- 2023–2025 年组织 AI 使用率动态图，支持年份切换与播放；能源图可点选“估计/预测”查看口径。
- 两个真实制造现场的图像切换，以及数据中心设施和运维人员影像；照片来自 Wikimedia Commons，许可见 `assets/README.md` 与网页末尾署名。
- 客服工作场景的有边界现场研究。
- 透明的工作流情景模拟器：节时、复核与返工成本共同决定净释放工时，所有输入均为用户假设。
- 可按调查、研究、部署、预测筛选数据来源。
- 数据来源、年份、研究范围和解释边界。

所有图形使用 SVG、CSS 和 Canvas 绘制；未引入外部图表运行依赖。字体使用本机系统回退栈。
